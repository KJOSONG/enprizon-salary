# P15：数据台重构 — 产量导向多维度交互仪表盘（2026-08-13）

> **背景**: 系统已从简单工资计算升级为员工管理、产量管理、评分管理、薪资管理综合平台。当前数据台以薪资指标为主（9 张薪资 KPI 卡片），产量数据仅有一张趋势折线图 + 一张核验表。用户要求重构为纯产量导向的多维度交互式仪表盘。

## 1. 需求概览

### 1.1 核心目标

将数据台从"薪资概览"转型为"产量指挥中心"，聚焦产量数据的多维度展示与交互分析。

### 1.2 移除内容

- 全部 9 张薪资 KPI 卡片（应发/奖金/罚款/预支/NSSF/司机津贴/实发/人数分类）
- 产量核验表（替换为钻工组产量对比图）
- 评分数据（不上数据台）
- 钻工耗材统计（futa/waya/kibiriti 已取消）

### 1.3 新增内容

- 6 张产量 KPI 卡片（NH/NL/MW/日均/日最高/白夜比）
- 增强产量趋势图（支持班次/日期/矿石筛选联动）
- 白班 vs 夜班对比双柱图（按矿石类型分 Tab）
- 钻工组产量堆叠柱状图（点击下钻逐日明细）
- 矿石类型占比环形图（点击联动高亮）
- 破碎产量横向逐日表格

## 3. 模块详细设计

### 3.1 控制栏

| 控件 | 类型 | 选项 | 默认值 | 行为 |
|------|------|------|--------|------|
| 月份选择 | 下拉 | 系统可用月份 | 当前月 | 切换月份 → 重新请求 `/api/production/dashboard` |
| 日期范围 | 双日期输入 | 1-31 | 月初 ~ 月末 | 过滤所有图表数据 |
| 班次切换 | Segmented Button | 全部 / 白班 / 夜班 | 全部 | 联动更新趋势图、KPI 卡片、白夜班对比、环形图 |
| 矿石筛选 | Segmented Button | 全部 / NH / NL / MW | 全部 | 联动更新趋势图、KPI 卡片、钻工组图、环形图 |

**交互**: 四个控件任一变化 → 前端纯过滤（不重新请求 API），所有图表 + KPI 卡片联动刷新。

### 3.2 KPI 卡片（6 张）

| 序号 | 卡片 | 指标 | 颜色 | 说明 |
|------|------|------|------|------|
| 1 | 本月 NH | NICKEL(H) 车次合计 | 蓝 (#4A90D9) | 受班次/矿石/日期筛选影响 |
| 2 | 本月 NL | NICKEL(L) 车次合计 | 绿 (#27AE60) | 同上 |
| 3 | 本月 MW | MAWE 车次合计 | 粉 (#E91E63) | 同上 |
| 4 | 日均车次 | (NH+NL+MW) / 有效天数 | 白 | 有效天数 = 有数据的天数 |
| 5 | 日最高 | 单日最高车次 + 日期 | 金 (#F5A623) | 格式: "132 (8/15)" |
| 6 | 白夜班比 | 白班总车次 : 夜班总车次 | 紫 (#9B59B6) | 格式: "1.2 : 1" |

**设计**: 大数字 + 小标签，与矿石颜色对应。style 继承现有 `stat-glass` 卡片风格。

### 3.3 产量趋势图（主图）

| 维度 | 内容 |
|------|------|
| 图表类型 | 多线折线图 (Chart.js) |
| X 轴 | 日期 (1-31) |
| Y 轴 | 车次 |
| 线条 | NH(蓝) / NL(绿) / MW(粉) |
| 数据源 | `shift_production` API 返回的 `day_nh/day_nl/day_mw` 或 `night_nh/night_nl/night_mw` 或 `total_nh/total_nl/total_mw` |

**交互**:
- 班次切换 → 线条更新为白班/夜班/合计数据
- 矿石筛选 → 仅显示选中矿石的线条
- 日期范围 → X 轴范围缩放
- Tooltip → 显示当日白班 + 夜班详细数值

### 3.4 白班 vs 夜班对比（双柱图）

| 维度 | 内容 |
|------|------|
| 图表类型 | 分组柱状图 (Chart.js) |
| X 轴 | 日期 |
| Y 轴 | 车次 |
| 每组 | 白班柱(浅色) + 夜班柱(深色) |
| Tab 切换 | NH / NL / MW / 合计 |

**交互**:
- Tab 切换矿石类型 → 柱子更新为对应矿石数据
- 班次筛选为"全部"时正常显示，选"白班/夜班"时此图可隐藏或仅显示对应柱
- Tooltip → 显示具体数值

### 3.5 钻工组产量对比（堆叠柱状图）

| 维度 | 内容 |
|------|------|
| 图表类型 | 堆叠柱状图 (Chart.js) |
| X 轴 | 钻工队长名 (BARAKA / JOHN / SHEDRACK) |
| Y 轴 | 产量 (车次) |
| 堆叠段 | NH(蓝) / NL(绿) / MW(粉) |
| 数据源 | `driller_production` API 返回的逐日明细 |

**交互**:
- 点击柱子 → 弹出 Modal 显示该钻工组逐日明细表格
  - 表格列: 日期 | NH | NL | MW | 合计
  - 合计行高亮
- 矿石筛选联动 → 堆叠段仅显示选中矿石（或全部）
- 班次切换对此图无影响（钻工产量不分班次）

### 3.6 矿石类型占比（环形图）

| 维度 | 内容 |
|------|------|
| 图表类型 | 环形图 (Doughnut, Chart.js) |
| 扇区 | NH(蓝) / NL(绿) / MW(粉) |
| 中心文字 | 总车次 |
| 数据 | 当前筛选条件下的合计 |

**交互**:
- 点击扇区 → 联动: 趋势图高亮对应矿石线 + 钻工组图切换为仅显示该矿石
- 过滤条件变化 → 自动重算占比

### 3.7 破碎产量（横向表格）

| 维度 | 内容 |
|------|------|
| 样式 | 横向滚动表格（日期多时） |
| 日期列 | 固定在左侧 |
| 数据行 | 袋数行 + 参与人数行 |
| 合计列 | 固定在右侧 |
| 数据源 | `crush_production` API 返回 |

**设计**:
- 有数据的日期单元格高亮（轻微背景色），无数据灰显
- 表头: 破碎产量 · 2026年8月
- 日期过多时横向滚动，日期列 + 合计列 sticky

## 5. API 设计

### 5.1 新增: `GET /api/production/dashboard`

**权限**: `login_required`

**返回**:
```json
{
  "month": "2026-08",
  "shift_production": [
    {
      "date": "2026-08-01",
      "day_nh": 80, "day_nl": 30, "day_mw": 20,
      "night_nh": 40, "night_nl": 15, "night_mw": 10,
      "total_nh": 120, "total_nl": 45, "total_mw": 30
    }
  ],
  "driller_production": [
    {
      "date": "2026-08-01",
      "captain": "BARAKA LAIZER",
      "nh": 500, "nl": 200, "mw": 100
    }
  ],
  "crush_production": [
    {
      "date": "2026-08-01",
      "bags": 150,
      "personnel_count": 5
    }
  ]
}
```

**与现有 `/production` 的区别**:
- `shift_production` 新增 `day_*` / `night_*` 分离字段（现有只有合计 `nh/nl/mw`）
- `driller_production` 返回逐日明细（现有返回队长汇总）
- 新增 `crush_production` 字段
- 移除 `driller_consumables`

### 5.2 保留现有

- `GET /production` 保留不变（产量录入页仍在使用）
- `GET /production-verify` 保留不变（钻工采集页核验）

## 6. 前端改动

### 6.1 文件清单

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `templates/index.html` | 重写 | Dashboard HTML 结构 + JS 逻辑 |
| `static/css/style.css` | 新增 | 控制栏、KPI 卡片、图表区、破碎表格、Modal 样式 |
| `static/js/i18n.js` | 新增 | 新的 i18n 键 |

### 6.2 删除的 JS 函数

- `renderDashboard()` — 替换为新版
- `renderProductionCharts()` — 合并到 `renderDashboardCharts()`
- `renderVerifyTable()` — 不再需要

### 6.3 新增的 JS 函数

| 函数 | 职责 |
|------|------|
| `loadDashboard()` | 入口: 请求 API + 渲染全部 |
| `renderDashboardKPI(data)` | 渲染 6 张 KPI 卡片 |
| `renderProductionTrend(data, filters)` | 渲染产量趋势折线图 |
| `renderDayNightCompare(data, filters)` | 渲染白夜班双柱对比图 |
| `renderDrillerGroupChart(data, filters)` | 渲染钻工组堆叠柱状图 |
| `renderCategoryPie(data, filters)` | 渲染矿石类型环形图 |
| `renderCrushTable(data)` | 渲染破碎产量横向表格 |
| `applyFilters()` | 统一过滤入口，联动刷新所有图表 |
| `showDrillerDetail(captain, data)` | 钻工组逐日明细 Modal |
| `destroyAllCharts()` | 销毁所有 Chart.js 实例 |

### 6.4 数据流

```
loadDashboard()
  → GET /api/production/dashboard
  → 存入 STATE._dashboardData
  → 初始化 filters = { month, dateFrom, dateTo, shift: 'all', ore: 'all' }
  → renderDashboardKPI()
  → renderProductionTrend()
  → renderDayNightCompare()
  → renderDrillerGroupChart()
  → renderCategoryPie()
  → renderCrushTable()

控制栏 onChange
  → 更新 filters
  → applyFilters()  → 前端过滤 STATE._dashboardData
  → 重新渲染所有图表 + KPI
```
