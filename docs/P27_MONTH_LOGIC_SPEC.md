# P27 月份逻辑 — 逻辑规格说明（AI 可读）

> **文档目的**：描述月份上下文、可用月份推导、Headless 预览模式、E 豁免与导出语义这一组变更的业务规则与约束，作为代码改造的对照规格。本文**不含任何代码**，只描述规则、公式、状态与开关，供 AI 与开发者阅读理解。
>
> **适用范围**：全系统月份筛选、薪资与出勤视图、导出与会话，所有涉及月份参数的交互均受本规格约束。
>
> **文档状态**：规则已与管理者确认，本文为冻结规格，见 `ARCHITECTURE.md` 数据流水线与 `AGENTS.md` 单轨及会话不变量。
>
> **重要定位**：本变更是**月份基础设施的补齐**，不改任何五轨计薪基础公式，不新增计薪轨道。由月份键与 Headless 标志驱动视图与导出行为。

---

## 0. 定位与开关（必读）

系统此前"月份"是隐式过滤，数据来源分散，空月无明确语义。P27 将其显式化：

| 概念 | 性质 | 说明 |
|---|---|---|
| 月份键 | 字符串标识 | 格式固定为 `YYYY-MM`，为全系统唯一月份上下文 |
| 可用月份表 | 权威来源推导 | 5 类数据源 + 未来 2 个合成月，去重后倒序呈现 |
| Headless 标志 | 布尔开关 | 标记"空月预览"态，仅出勤可录，手写数据不被采集覆盖 |
| 会话月份 | 粘性上下文 | 登录后保持，用户切月后保持至下次切月或重载 |

**开关含义**：
- 有源数据月份，Headless 为假，全部 5 轨与出勤按采集与覆盖正常计算。
- 无源数据月份，Headless 为真，前端显示预览横幅，仅允许出勤三种手动标记的录入。
- 合成月份同样可进入 Headless 预览，支持提前排班与出勤预填。

---

## 1. 设计目标与原则

| 目标 | 说明 |
|---|---|
| 月份即真相 | 任何视图与导出的月份必须显式由用户所选月份决定，不允许用缓存残留或隐式回退产生歧义 |
| 空月可用 | 即使当月尚无任何产量或出勤采集，也能打开该月并记录出勤，不阻塞现场排班 |
| 手写不丢 | 预览期手写的出勤标记在后续采集数据到位后不被覆盖，合并时以手写为准 |
| 导出即所见 | 导出的文件名与文件内容必须与用户请求的月份一致，不允许文件名与数据月份错位 |
| 会话稳定 | 服务重启不踢人，同一用户的月份上下文与登录态跨重启保持一致 |

以上目标与 `AGENTS.md` 单轨不变量与总额守恒、`ARCHITECTURE.md` 逐日单轨合并约束保持一致。

## 2. 月份键定义

- 键格式为 `YYYY-MM`，月位两位数补零，例如 `2026-08`。
- 所有筛选、存储、展示均以该键为单位，不使用日级键做月份聚合。
- 特殊值 `all` 仅用于"全量不筛选"场景，不参与 Headless 判定与导出命名。
- 前端周期栏显示当前月份键，隐藏的选择器保持同步，避免新旧入口不一致。

---

## 3. 可用月份权威来源（5 类 + 合成）

可用月份列表为以下来源的并集，去重后按字符串倒序排列：

| 序号 | 来源 | 说明 |
|---|---|---|
| 1 | 采集提交日期 | 提交表中的日期字段按前缀截取月份，去重 |
| 2 | 出勤覆盖日期 | 出勤覆盖表中的日期字段按前缀截取月份，去重 |
| 3 | 奖惩月份 | 奖惩表中的月份字段直接去重 |
| 4 | 已加载主数据日期 | 当前主数据日期集合按前缀截取月份 |
| 5 | 历史月份表 | 已持久化的月度薪资快照中的月份去重 |
| 6 | 合成月份 | 当前自然月与未来 2 个月自动补齐，支持提前记录 |

**约束**：
- 任一来源出现即视为该月"可用"，不因另一来源为空而剔除。
- 合成月份即使无任何数据也必须出现在列表中，保证空月可点开。
- 返回结果为倒序字符串数组，前端据此渲染月份选择器并默认选中当前自然月。

## 4. Headless 与 Preview 语义

当用户切入某月份且主数据日期集合为空、但员工表非空时，系统进入 Headless 预览态：

| 字段 | 行为 |
|---|---|
| 日期列 | 按该月份自然日历天数生成连续日期，例如 1 至 31 日 |
| 产量 | 置空，不生成任何产量记录 |
| 出勤 | 置空，仅保留日期骨架，等待手写 |
| 标志 | 置为真，前端据此展示顶部预览横幅 |
| 提示文案 | 明确告知"当月暂无源数据，已生成日期列，仅支持出勤记录" |

**允许操作**：
- 仅允许出勤标记的手动录入，取值限于出勤、旷工、请假三种基础状态的切换。
- 不允许在该态下提交产量类采集，产量采集仍需走正常表单。

**合并保证**：
- 后续该月采集数据到位后，手写出勤标记不被采集回填覆盖，以手写为准。
- 日期骨架在有真实数据后被真实日期集合自然替代，不残留合成日期。

**前端表现**：
- 出勤页顶部出现预览横幅，仅在该标志为真时显示。
- 切换离开该月后横幅自动消失。

## 5. 公式与 E 豁免交互

E 豁免为"未出勤、不计薪、不计 A_W 惩罚"的特殊出勤码，与月份预览协同如下：

| 场景 | 规则 |
|---|---|
| Headless 下的 E | 允许标记，语义与非 Headless 一致，计薪时不产生日薪或月薪出勤天数 |
| 计件分配排除 | E 与旷工、请假、年假计薪同列，计件分母中排除 |
| 月末系数保护 | E 计入豁免天数集合，满勤分母同步扣减，不对出勤系数造成惩罚 |
| 导出 | E 在出勤导出中按原码导出，不转义为出勤 |

**边界**：
- 空月 E 标记同样参与可用月份来源的出勤覆盖集合，确保空月因手写 E 而被识别为可用月份。
- E 不影响 Headless 判定本身，Headless 仅由"有无主数据日期"决定。

## 6. 状态表

| 状态组合 | 主数据日期 | 员工表 | Headless | 视图行为 | 出勤可写 | 薪资计算 |
|---|---|---|---|---|---|---|
| A 正常月 | 非空 | 非空 | 假 | 全量展示 | 是 | 全轨按采集与覆盖计算 |
| B 空月预览 | 空 | 非空 | 真 | 日期骨架 + 横幅 | 仅三种基础标记 | 仅出勤驱动的日薪与月薪，计件为零 |
| C 全空 | 空 | 空 | 假 | 提示缺员工 | 否 | 拒绝计算，提示先导入员工 |
| D 全量视图 | 忽略 | 非空 | 假 | 不筛选 | 是 | 全量 |

**推导**：
- 仅 B 态 Headless 为真，其余均为假。
- B 态经后续采集补齐后自然转为 A 态，无需用户手动退出预览。

## 7. Stale Page 契约（过期页面约束）

月份切换为粘性全局上下文，切换后以下页面视为过期，必须刷新或重算后才可信：

| 页面 | 是否过期 | 原因 |
|---|---|---|
| 薪资总表 | 是 | 金额按月重算，旧月结果不可复用 |
| 日工资明细 | 是 | 逐日金额与总表同源，必须同月 |
| 出勤网格 | 是 | 日期列与标记均按月过滤 |
| 员工列表出勤统计 | 是 | 统计口径依赖当月出勤 |
| 产量总览 | 是 | 产量按月过滤 |
| 评分汇总与客观记录 | 是 | 评分按月过滤 |
| 系统配置参数页 | 否 | 参数为全局，不随月份变化 |

**前端责任**：
- 切月成功后依次刷新薪资、出勤、员工、产量数据源，或标记为脏并在下次进入时拉取。
- 切月失败或被降级为只读查询时，不更新周期栏，避免显示与数据不一致。

## 8. 导出语义

| 规则 | 说明 |
|---|---|
| 文件名含月份 | 导出文件名必须包含所请求月份键，无月份时才允许无后缀的通用名 |
| 数据与月份一致 | 文件内容必须与请求月份过滤后的数据集一致，不允许用缓存中另一月份的数据填充 |
| 薪资导出 | 按请求月份的薪资结果生成，与当前视图月份一致 |
| 出勤导出 | 按请求月份的出勤网格生成，日期列与网格列一致 |
| 工资单导出 | 单人与批量工资单均按请求月份生成，文件名含员工与月份 |

**校验**：
- 请求带月份参数时，后端以该参数为准，不以内部缓存月份为准。
- 未带月份参数时，以当前会话月份为准，并回退到可用的最新月份。

## 9. 会话与密钥不变量

`KILWA_SECRET_KEY` 为会话加密密钥，相关不变量如下：

| 不变量 | 说明 |
|---|---|
| 已配置密钥不轮换 | 部署环境必须持久配置该密钥，服务重启不改变密钥值 |
| 未配置则会话脆弱 | 未配置时每次重启随机生成，全部用户会话失效，需重新登录 |
| 与月份无关 | 月份上下文存于内存与会话，密钥仅保证会话不丢失，不参与月份推导 |
| 生产与本地一致性 | 生产环境与本地开发均需显式配置，避免"本地正常、线上掉线"的误判 |

该不变量与 `AGENTS.md` 会话与认证章节及 `ARCHITECTURE.md` 部署配置保持一致。

## 11. 验收要点

- 可用月份包含采集、出勤覆盖、奖惩、主数据、历史快照五类来源，外加当前与未来两个合成月。
- 切入无数据月份自动生成当月全部自然日期，仅出勤可录，并显示预览横幅。
- 预览期手写出勤在后续采集到位后不被覆盖。
- 切月后薪资、出勤、产量、评分页面均刷新至新月份，无残留旧月数据。
- 导出文件名含月份，文件内容与所请求月份一致。
- 配置密钥后重启不掉线，未配置则重启后全部会话失效。
